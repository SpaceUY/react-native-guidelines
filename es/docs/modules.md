# Módulos

Piezas reutilizables que el equipo ya construyó y puso en producción, empaquetadas para que el
próximo proyecto arranque desde ellas y no desde cero. Cada página dice qué resuelve el módulo,
qué necesita de afuera del código (cuentas, aprobaciones, proveedores) y cómo conectarlo.

Acá un módulo es un repositorio aparte con versiones. Se instala con un tag fijo y su README
tiene la API completa; estas páginas son la guía del equipo alrededor.
