# Primeros Pasos

Todo lo que necesitás para pasar de una máquina recién formateada a la app
corriendo. Leé estas páginas en orden la primera vez; después, usalas como
checklist.

1. **Requisitos Previos y Herramientas** — instalá las herramientas y creá las cuentas.
2. **Crear o Clonar un Proyecto** — empezá de cero o sumate a un repo existente.
3. **Variables de Entorno** — configurá tu `.env`.
4. **Ejecutar la App** — lanzala en un simulador o dispositivo.
