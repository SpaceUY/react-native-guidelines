# Compilación y Distribución

Cómo hacer llegar los builds a la gente. Hay **dos caminos que nunca se
mezclan**:

- **Builds internos** para testers → **Firebase App Distribution**.
- **Producción** para las tiendas de apps → **EAS Submit**.

Leé **Conceptos** primero — cinco minutos ahí te ahorran una tarde de debugging.
