# Arquitectura del Proyecto

Cómo organizamos el código para que cualquier proyecto se sienta igual: una
capa de ruteo delgada, carpetas de features que son dueñas de su porción de
la app, y una capa compartida para código genuinamente transversal. Además,
cómo registramos las decisiones que nos trajeron hasta acá.

- **Estructura Basada en Features** — dónde vive el código y por qué.
- **Reglas de Importación y Alias de Rutas** — cómo los módulos se referencian
  entre sí sin crear ciclos.
- **Registros de Decisiones de Arquitectura** — cómo capturamos el "por qué".
