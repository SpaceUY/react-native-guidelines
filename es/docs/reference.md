# Referencia

## Glosario

| Término | Significado |
| --- | --- |
| **EAS** | Expo Application Services — las herramientas de Expo para build, submit y updates. |
| **Build profile** | Una configuración de build con nombre en `eas.json` (`development`, `preview`, `production`). |
| **Ad-hoc** | Una distribución de iOS que solo se instala en dispositivos cuyo UDID está en el provisioning profile. |
| **Provisioning profile** | El archivo de Apple que define qué app, certificado y dispositivos pueden correr un build. |
| **UDID** | El identificador único de un dispositivo; debe estar registrado para instalaciones ad-hoc. |
| **Dev client** | Un build a medida de tu app que incluye sus módulos nativos (a diferencia de Expo Go). |
| **App Distribution** | El canal gratuito de Firebase para entregar builds de prueba a testers. |
| **`APP_ENV`** | El selector de entorno (`development` / `preview` / `production`) que maneja la configuración dinámica. |
| **Barrel** | Un `index.ts` que re-exporta la superficie pública de un módulo. |
