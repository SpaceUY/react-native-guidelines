# Getting Started

Everything you need to go from a fresh machine to a running app. Read these in
order the first time; after that, use them as a checklist.

1. **Prerequisites & Tooling** — install the tools and create the accounts.
2. **Create or Clone a Project** — start fresh or join an existing repo.
3. **Environment Variables** — set up your `.env`.
4. **Running the App** — launch it on a simulator or device.
