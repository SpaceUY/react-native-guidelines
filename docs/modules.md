# Modules

Reusable pieces the team has already built and shipped to production, packaged so the next
project starts from them instead of from zero. Each page says what the module solves, what it
needs from outside the codebase (accounts, approvals, vendors) and how to wire it.

A module here is a separate repository with versions. Install it with a pinned tag and read its
README for the full API; these pages are the team guide around it.
